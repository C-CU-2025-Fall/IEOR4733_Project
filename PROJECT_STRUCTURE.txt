IEOR4733_Project — Project Structure
================================================================================

ROOT  (top-level files)
├── baseline_run.py              Core backtesting engine — loads contracts,
│                                computes returns, prints Table 3 metrics for
│                                Long Only / Sign(R) / MACD
├── config.py                    Global configuration: ASSET_CLASSES, contract
│                                exclusions, SOURCE_OVERRIDES, sigma targets
├── data_loader.py               load_clc_full() — reads CLCData RAD CSVs,
│                                validates prices, aligns dates
├── strategies.py                Position-sizing logic for Long Only, Sign(R),
│                                MACD strategies
├── metrics.py                   compute_metrics(), max_drawdown_from_path(),
│                                cagr_from_path()
├── indicators.py                Technical indicators: MACD signal, EWM vol, etc.
├── vol_scaling.py               Volatility-targeting and position scaling
├── repro_analysis.py            Diagnostic script: reproduced vs paper metrics
├── generate_table3_comparison.py  Quick console Table 3 comparison (all 6 strategies)
├── generate_table3_markdown.py  Writes Table 3 results to a Markdown file
├── generate_results_tables.py   Exports full results CSVs used by the Streamlit app
├── test_baseline.py             Unit tests for the baseline pipeline
├── verify_setup.py              Checks data files and dependencies are present
├── run_app.sh                   One-command launcher: activates venv + streamlit
├── streamlit_requirements.txt   Python dependencies for the Streamlit app
├── README.md                    Project overview, quickstart, tab guide,
│                                folder descriptions
├── PROJECT_MEMORY.md            Running development log; read before resuming work
├── PROJECT_STRUCTURE.txt        This file
├── STREAMLIT_GUIDE.md           Additional Streamlit usage notes (legacy)
└── DEPLOYMENT_COMPLETE.md       Deployment summary (legacy)

================================================================================

src/                             Streamlit application code
├── __init__.py
├── app/
│   ├── main.py                  ★ Entry point — all UI layout, data loading,
│   │                              chart rendering (4 tabs)
│   │                              TAB 1: Strategy Comparison
│   │                              TAB 2: Performance Metrics
│   │                              TAB 3: Risk Analysis
│   │                              TAB 4: Data Pipeline
│   ├── main_backup_v1.py        Earlier version kept for reference
│   └── main_complex.py          Experimental richer version (not served)
├── core/                        Modular core library (mirrors root-level scripts)
│   ├── data/loader.py           Mirrors data_loader.py
│   ├── strategies/base.py       Mirrors strategies.py
│   ├── strategies/runner.py     Mirrors baseline_run.py
│   ├── metrics/calculator.py    Mirrors metrics.py
│   ├── utils/indicators.py      Mirrors indicators.py
│   └── models/                  Model wrappers (dqn.py, a2c.py, regime.py)
├── notebooks/                   Jupyter notebooks under src
└── scripts/                     Utility scripts under src

================================================================================

data/                            All market data
├── CLC/                         ★ CLCData RAD format — one file per contract,
│   │                              three adjustment variants per symbol:
│   │                              {SYM}_RAD.CSV  — ratio-adjusted (primary)
│   │                              {SYM}_NON.CSV  — unadjusted
│   │                              {SYM}_REV.CSV  — reverse-adjusted
│   └── (50 contracts × 2-3 variants ≈ ~130 CSV files)
├── yahoo/                       Yahoo Finance daily price CSVs (equity fallback)
├── index_data.csv               Pre-merged index-level daily prices
└── risk_free_rate.csv           Daily risk-free rate series (3-month T-bill)

================================================================================

reproduction_of_figures/         Reproduce the paper's strategy-comparison charts
├── strategies_comparison.ipynb  ★ Master notebook — runs all 6 strategies,
│                                  exports baseline_results/ CSVs
├── baseline_results/            ★ Pre-computed CSVs (pure RAD, no overrides)
│   │                              READ BY THE STREAMLIT APP
│   └── baseline_{strategy}_{asset}.csv  (e.g. baseline_long_only_commodity.csv)
├── a2c_csv_data/                Older A2C CSVs with long-override adjustments
│   └── pnl_{asset}_{period}.csv          (used for cross-checks only)
└── *.png                        Comparison figures at various dev stages

================================================================================

regime_detection/                Route B: FFT-based regime model on top of A2C
├── timeseries_fft_regime.py     Core FFT regime classifier
├── route_b_train.py             Training script for regime-conditioned A2C
├── route_b_experiment.ipynb     Exploratory notebook for regime analysis
├── reeval_route_b_final.py      ★ Final evaluation — generates results/ CSVs
├── results/                     Per-asset, per-period cumulative return CSVs
│   └── pnl_routeB_{asset}_{period}.csv
├── regime_probabilities.png     Regime probability time-series plot
└── regime_timeseries.png        Regime classification overlay plot

================================================================================

drl_models/                      Deep RL model weights and implementation
├── a2c/
│   ├── a2c_model.py             A2C model architecture (LSTM Actor-Critic)
│   ├── loaddata.py              Data loader for A2C training/evaluation
│   ├── Original Reward/         Trained .pt weights — original reward function
│   │   └── a2c_{asset}_period{n}.pt
│   ├── Extension Reward/        Trained .pt weights — extended reward function
│   │   └── a2c_rb_{asset}_period{n}.pt
│   └── a2c_results_wide改.csv   Wide-format A2C results (all assets, periods)
└── dqn/
    ├── (DQN model implementation and trained weights)
    └── figures/data/            DQN output data for Streamlit TAB 1

================================================================================

rl_models/                       Legacy path (kept for backward compatibility)
└── a2c_results_wide.csv         Wide-format A2C results used by the app

================================================================================

├── long_only/                   Long Only — sweep scripts and audit tools

│   ├── frontier_40plus_enumeration.py  Enumerates clean 40+ frontiers
│   ├── calmar_alignment_iteration.py   Iterates toward Calmar alignment
│   ├── results/                 Roll-date and roll-price validation CSVs
│   └── (other audit and probe scripts)
├── macd/
│   ├── run_legacy_41_macd.py    MACD upper-bound reproduction
│   └── frontier_40plus_enumeration_macd.py
└── signr/
    ├── run_legacy_41_signr.py   Sign(R) upper-bound reproduction
    └── frontier_40plus_enumeration_signr.py
